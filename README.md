# Incog website

Website for **Incog**, a software company in Egypt that builds custom systems for businesses.

- One file: `index.html` (no build step)
- English and Arabic, with live demos of the El Baraka ordering and Scene seat-booking concepts

## Deploy on Vercel

Import this repository in Vercel, keep Framework Preset as **Other**, and deploy. Every push to `main` redeploys the site.
